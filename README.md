# MEOW×404 Bot

MEOW×404 — Telegram-бот, управляющий комьюнити канала @meowx404. Он реализует реферальную систему, миссии с наградами, ранги «хвостов», принимает платные сообщения и предоставляет админ-панель.

## Возможности

- `/start` с deep-link и привязкой реферального кода.
- Проверка подписки на канал и чат обсуждений.
- Просмотр профиля, ранга, статистики рефералов и активных миссий.
- Участие в миссиях, загрузка пруфов и лог начислений хвостов.
- Админ-панель с быстрым доступом к созданию миссий, выдаче хвостов, установке ранга и экспорту CSV.
- Логирование всех действий пользователей в таблицу `actions`.

## Требования

- Python 3.11+
- PostgreSQL 14+
- Установленный `poetry` или `pip`
- Telegram Bot Token

## Быстрый старт (Docker Compose)

```bash
docker compose up --build
```

## Локальный запуск

1. Скопируйте `.env` и заполните параметры окружения:

```bash
cp .env .env.local
```

Заполните `BOT_TOKEN`, `DATABASE_URL`, `CHANNEL_ID`, `DISCUSSION_ID`, `REF_BASE_URL` и `ADMIN_IDS`.

2. Установите зависимости и запустите бота:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

## Структура проекта

```
app/
  config.py        # Настройки и ранги
  db.py            # Подключение к БД
  models.py        # SQLAlchemy ORM-модели
  handlers/        # Хендлеры aiogram (пользователи, админы)
  services/        # Бизнес-логика: пользователи, миссии, действия
  utils/           # Тексты и клавиатуры
bot.py             # Точка входа aiogram
main.py            # Алиас запуска
requirements.txt   # Зависимости
start.sh           # Скрипт запуска
```

## Миграции

Для MVP структура БД создаётся автоматически при запуске (см. `init_database`). Для продакшена рекомендуется подключить Alembic и описать миграции.

## Разработка

- Хендлеры разделены на пользовательские и административные.
- `app/services` инкапсулируют бизнес-правила: начисление хвостов, логирование действий, создание миссий.
- `app/utils` содержит генераторы текстов и клавиатуры для Telegram.

## Тестовые команды

- `/start` — onboarding и проверка подписки.
- `/profile`, `/rank`, `/missions`, `/ref`, `/help` — пользовательские команды.
- `/admin`, `/mission_new`, `/give`, `/setrank`, `/export` — административные команды.
